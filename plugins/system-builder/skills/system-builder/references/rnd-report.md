# RND Report Template — docs/01-RND.md

Use this exact structure. Keep it tidy and skimmable; the user reads this to approve Phase 1.

# RND Report: [Project Name]

## Executive summary
5–10 sentences: what was researched, the single most important takeaway, and the recommended direction.

## Research missions
Table: mission | subagent role | sources covered | status.

## Key findings by theme
Group findings into themes (not by agent). Each finding: one short paragraph + source links. Flag anything two agents disagreed on and how it was resolved.

## Existing solutions & prior art
Table: name | link | what it does well | weaknesses/gaps | license/pricing. Include both commercial products and open-source repos.

## Community insights
What real users on Reddit/forums/social media complain about, wish existed, or warn against. Quote sparingly, paraphrase mostly, always link.

## Recommended direction & tech options
2–3 viable options with tradeoffs (effort, risk, fit with the brief). Mark the recommended one and say why.

## Risks & unknowns
Things research could not settle, plus anything that could invalidate the plan later.

## Open questions for the user
Only questions that actually change Phase 2 decisions.

## Sources
Full list of links used.
